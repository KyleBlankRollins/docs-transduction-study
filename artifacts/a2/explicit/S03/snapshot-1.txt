  - heading "Share state between islands" [level=1]
  - paragraph:
    - text: When building an Astro website with
    - link "islands architecture / partial hydration":
      - /url: /en/concepts/islands/
    - text: ", you may have run into this problem:"
    - strong: I want to share state between my components.
  - paragraph:
    - text: UI frameworks like React or Vue may encourage
    - link "“context” providers":
      - /url: https://react.dev/learn/passing-data-deeply-with-context
    - text: for other components to consume. But when
    - link "partially hydrating components":
      - /url: /en/guides/framework-components/#hydrating-interactive-components
    - text: within Astro or Markdown, you can’t use these context wrappers.
  - paragraph:
    - text: "Astro recommends a different solution for shared client-side storage:"
    - link "Nano Stores":
      - /url: https://github.com/nanostores/nanostores
      - strong: Nano Stores
    - text: .
  - strong: "Related recipe:"
  - link "Share state between Astro components":

  - heading "Why Nano Stores?" [level=2]
  - link "Section titled “Why Nano Stores?”":
    - /url: "#why-nano-stores"
  - paragraph:
    - text: The
    - link "Nano Stores":
      - /url: https://github.com/nanostores/nanostores
    - text: "library allows you to author stores that any component can interact with. We recommend Nano Stores because:"
  - list:
    - listitem:
      - strong: They’re lightweight.
      - text: Nano Stores ship the bare minimum JS you’ll need (less than 1 KB) with zero dependencies.
    - listitem:
      - strong: They’re framework-agnostic.
      - text: This means sharing state between frameworks will be seamless! Astro is built on flexibility, so we love solutions that offer a similar developer experience no matter your preference.
  - paragraph: "Still, there are a number of alternatives you can explore. These include:"
  - list:
    - listitem:
      - link "Svelte’s built-in stores":
        - /url: https://svelte.dev/tutorial/writable-stores
    - listitem:
      - link "Solid signals":
        - /url: https://www.solidjs.com/docs/latest
      - text: outside of a component context
    - listitem:
      - link "Vue’s reactivity API":
        - /url: https://vuejs.org/guide/scaling-up/state-management.html#simple-state-management-with-reactivity-api
    - listitem:
      - link "Sending custom browser events":
        - /url: https://developer.mozilla.org/en-US/docs/Web/Events/Creating_and_triggering_events
      - text: between components
