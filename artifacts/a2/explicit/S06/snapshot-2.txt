- main:
  - heading "Deploy your Astro Site with Deno" [level=1]
  - paragraph:
    - text: You can deploy a static or on-demand rendered Astro site using Deno, either on your own server, or to
    - link "Deno Deploy":
      - /url: https://deno.com/deploy
    - text: ", a distributed system that runs JavaScript, TypeScript, and WebAssembly at the edge, worldwide."
  - paragraph: This guide includes instructions for running your Astro site on your own server with Deno, and deploying to Deno Deploy through GitHub Actions or the Deno Deploy CLI.
  - heading "Requirements" [level=2]
  - link "Section titled “Requirements”":
    - /url: "#requirements"
  - paragraph:
    - text: This guide assumes you already have
    - link "Deno":
      - /url: https://deno.com/
    - text: installed.
  - heading "Project Configuration" [level=2]
  - link "Section titled “Project Configuration”":
    - /url: "#project-configuration"
  - paragraph: Your Astro project can be deployed as a static site, or as an on-demand rendered site.
  - heading "Static Site" [level=3]
  - link "Section titled “Static Site”":
    - /url: "#static-site"
  - paragraph: Your Astro project is a static site by default. You don’t need any extra configuration to deploy a static Astro site with Deno, or to Deno Deploy.
  - heading "Adapter for on-demand rendering" [level=3]
  - link "Section titled “Adapter for on-demand rendering”":
    - /url: "#adapter-for-on-demand-rendering"
  - paragraph: "To enable on-demand rendering in your Astro project using Deno, and to deploy on Deno Deploy:"
  - list:
    - listitem:
      - paragraph:
        - text: Install
        - link "the @deno/astro-adapter adapter":
          - /url: https://github.com/denoland/deno-astro-adapter
          - text: the
          - code: "@deno/astro-adapter"
          - text: adapter
        - text: "to your project’s dependencies using your preferred package manager:"
      - tablist:
        - tab "npm" [selected]
        - tab "pnpm"
        - tab "Yarn"
      - tabpanel "npm":
        - figure "Terminal window":
          - text: Terminal window
          - code: npm install @deno/astro-adapter
          - button "Copy to clipboard"
    - listitem:
      - paragraph:
        - text: Update your
        - code: astro.config.mjs
        - text: project configuration file with the changes below.
      - figure "astro.config.mjs":
        - text: astro.config.mjs
        - code: "import { defineConfig } from 'astro/config'; + import deno from '@deno/astro-adapter'; export default defineConfig({ + output: 'server', + adapter: deno(), });"
        - button "Copy to clipboard"
    - listitem:
      - paragraph:
        - text: Update your
        - code: preview
        - text: script in
        - code: package.json
        - text: with the change below.
      - figure "package.json":
        - text: package.json
        - region:
          - code: "{ \"scripts\": { \"dev\": \"astro dev\", \"start\": \"astro dev\", \"build\": \"astro build\", - \"preview\": \"astro preview\" + \"preview\": \"deno run --allow-net --allow-read --allow-env ./dist/server/entry.mjs\" } }"
        - button "Copy to clipboard"
      - paragraph: You can now use this command to preview your production Astro site locally with Deno.
      - tablist:
        - tab "npm" [selected]
        - tab "pnpm"
        - tab "Yarn"
      - tabpanel "npm":
        - figure "Terminal window":
          - text: Terminal window
          - code: npm run preview
          - button "Copy to clipboard"
  - heading "How to deploy" [level=2]
  - link "Section titled “How to deploy”":
    - /url: "#how-to-deploy"
  - paragraph: You can run your Astro site on your own server, or deploy to Deno Deploy through GitHub Actions or using Deno Deploy’s CLI (command line interface).
  - heading "On your own server" [level=3]
  - link "Section titled “On your own server”":
    - /url: "#on-your-own-server"
  - list:
    - listitem:
      - paragraph: Copy your project onto your server.
    - listitem:
      - paragraph: "Install the project dependencies using your preferred package manager:"
      - tablist:
        - tab "npm" [selected]
        - tab "pnpm"
        - tab "Yarn"
      - tabpanel "npm":
        - figure "Terminal window":
          - text: Terminal window
          - code: npm install
          - button "Copy to clipboard"
    - listitem:
      - paragraph: "Build your Astro site with your preferred package manager:"
      - tablist:
        - tab "npm" [selected]
        - tab "pnpm"
        - tab "Yarn"
      - tabpanel "npm":
        - figure "Terminal window":
          - text: Terminal window
          - code: npm run build
          - button "Copy to clipboard"
    - listitem:
      - paragraph: "Start your application with the following command:"
      - tablist:
        - tab "Static" [selected]
        - tab "On demand"
      - tabpanel "Static":
        - figure "Terminal window":
          - text: Terminal window
          - code: deno run -A jsr:@std/http/file-server dist
          - button "Copy to clipboard"
  - heading "GitHub Actions Deployment" [level=3]
  - link "Section titled “GitHub Actions Deployment”":
    - /url: "#github-actions-deployment"
  - paragraph:
    - text: If your project is stored on GitHub, the
    - link "Deno Deploy website":
      - /url: https://dash.deno.com/
    - text: will guide you through setting up GitHub Actions to deploy your Astro site.
  - list:
    - listitem:
      - paragraph: Push your code to a public or private GitHub repository.
    - listitem:
      - paragraph:
        - text: Sign in on
        - link "Deno Deploy":
          - /url: https://dash.deno.com/
        - text: with your GitHub account, and click on
        - link "New Project":
          - /url: https://dash.deno.com
        - text: .
    - listitem:
      - paragraph:
        - text: Select your repository, the branch you want to deploy from, and select
        - strong: GitHub Action
        - text: mode. (Your Astro site requires a build step, and cannot use Automatic mode.)
    - listitem:
      - paragraph:
        - text: In your Astro project, create a new file at
        - code: .github/workflows/deploy.yml
        - text: and paste in the YAML below. This is similar to the YAML given by Deno Deploy, with the additional steps needed for your Astro site.
      - tablist:
        - tab "Static" [selected]
        - tab "On demand"
      - tabpanel "Static":
        - figure ".github/workflows/deploy.yml":
          - text: .github/workflows/deploy.yml
          - region:
            - code: "name: Deploy on: [push] jobs: deploy: name: Deploy runs-on: ubuntu-latest permissions: id-token: write # Needed for auth with Deno Deploy contents: read # Needed to clone the repository steps: - name: Clone repository uses: actions/checkout@v7 # Not using npm? Change `npm ci` to `pnpm i` or `yarn install` - name: Install dependencies run: npm ci # Not using npm? Change `npm run build` to `pnpm run build` or `yarn run build` - name: Build Astro run: npm run build - name: Upload to Deno Deploy uses: denoland/deployctl@v1 with: project: my-deno-project # TODO: replace with Deno Deploy project name entrypoint: jsr:@std/http/file-server root: dist"
          - button "Copy to clipboard"
    - listitem:
      - paragraph: After committing this YAML file, and pushing to GitHub on your configured deploy branch, the deploy should begin automatically!
      - paragraph:
        - text: You can track the progress using the “Actions” tab on your GitHub repository page, or on
        - link "Deno Deploy":
          - /url: https://dash.deno.com
        - text: .
  - heading "CLI Deployment" [level=3]
  - link "Section titled “CLI Deployment”":
    - /url: "#cli-deployment"
  - list:
    - listitem:
      - paragraph:
        - text: Install the
        - link "Deno Deploy CLI":
          - /url: https://docs.deno.com/deploy/manual/deployctl
        - text: .
      - figure "Terminal window":
        - text: Terminal window
        - code: deno install -gArf jsr:@deno/deployctl
        - button "Copy to clipboard"
    - listitem:
      - paragraph: "Build your Astro site with your preferred package manager:"
      - tablist:
        - tab "npm" [selected]
        - tab "pnpm"
        - tab "Yarn"
      - tabpanel "npm":
        - figure "Terminal window":
          - text: Terminal window
          - code: npm run build
          - button "Copy to clipboard"
    - listitem:
      - paragraph:
        - text: Run
        - code: deployctl
        - text: to deploy!
      - tablist:
        - tab "Static" [selected]
        - tab "On demand"
      - tabpanel "Static":
        - figure "Terminal window":
          - text: Terminal window
          - code: cd dist && deployctl deploy jsr:@std/http/file-server
          - button "Copy to clipboard"
      - paragraph:
        - text: You can track all your deploys on
        - link "Deno Deploy":
          - /url: https://dash.deno.com
        - text: .
    - listitem:
      - paragraph:
        - text: (Optional) To simplify the build and deploy into one command, add a
        - code: deploy-deno
        - text: script in
        - code: package.json
        - text: ", adapting it for your preferred package manager."
      - tablist:
        - tab "Static" [selected]
        - tab "On demand"
      - tabpanel "Static":
        - figure "package.json":
          - text: package.json
          - region:
            - code: "{ \"scripts\": { \"dev\": \"astro dev\", \"start\": \"astro dev\", \"build\": \"astro build\", \"preview\": \"astro preview\", + \"deno-deploy\": \"npm run build && cd dist && deployctl deploy jsr:@std/http/file-server\" } }"
          - button "Copy to clipboard"
      - paragraph: Then you can use this command to build and deploy your Astro site in one step.
      - tablist:
        - tab "npm" [selected]
        - tab "pnpm"
        - tab "Yarn"
      - tabpanel "npm":
        - figure "Terminal window":
          - text: Terminal window
          - code: npm run deno-deploy
          - button "Copy to clipboard"
