  - heading "Nesting framework components" [level=2]
  - link "Section titled “Nesting framework components”":
    - /url: "#nesting-framework-components"

    - text: src/pages/nested-components.astro

  - complementary "Caution":
    - paragraph:
      - text: "Remember: framework component files themselves (e.g."
      - code: .jsx
      - text: ","
      - code: .svelte
      - text: ) cannot mix multiple frameworks.
  - paragraph: This allows you to build entire “apps” in your preferred JavaScript framework and render them, via a parent component, to an Astro page.
  - complementary "Note":
    - paragraph: Astro components are always rendered to static HTML, even when they include framework components that are hydrated. This means that you can only pass props that don’t do any HTML rendering. Passing React’s “render props” to framework components from an Astro component will not work, because Astro components can’t provide the client runtime behavior that this pattern requires. Instead, use named slots.
