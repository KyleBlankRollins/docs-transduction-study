- main:
  - heading "Building Astro sites with AI tools" [level=1]
  - paragraph: AI-powered editors and agentic coding tools generally have good knowledge of Astro’s core APIs and concepts. However, some may use older APIs and may not be aware of newer features or recent changes to the framework.
  - paragraph: This guide covers how to enhance AI tools with up-to-date Astro knowledge and provides best practices for building Astro sites with AI assistance.
  - heading "Astro Docs MCP Server" [level=2]
  - link "Section titled “Astro Docs MCP Server”":
    - /url: "#astro-docs-mcp-server"
  - paragraph: You can ensure your AI tools have current Astro knowledge through the Astro Docs MCP (Model Context Protocol) server. This provides real-time access to the latest documentation, helping AI tools avoid outdated recommendations and ensuring they understand current best practices.
  - paragraph:
    - text: "What is MCP?:"
    - link "Model Context Protocol":
      - /url: https://modelcontextprotocol.io/
    - text: (MCP) is a standardized way for AI tools to access external tools and data sources.
  - paragraph: Unlike AI models trained on static data, the MCP server provides access to the latest Astro documentation. The server is free, open-source, and runs remotely with nothing to install locally.
  - paragraph:
    - text: The Astro Docs MCP server uses the
    - link "kapa.ai":
      - /url: https://www.kapa.ai/
    - text: API to maintain an up-to-date index of the Astro documentation.

  - paragraph:
    - strong: "Added in:"
    - code: astro@7.0.0
  - paragraph:
    - text: When an AI coding agent is detected,
    - code: astro dev
    - text: automatically starts the dev server as a detached background process. This prevents the dev server from blocking the agent’s terminal and allows it to continue working while the server runs.
  - paragraph:
    - text: A lock file (

    - text: ) is written when the dev server starts, recording the server’s URL, port, and PID. This prevents duplicate servers from being started for the same project.
  - paragraph:
    - text: If you are not using an AI coding agent,
    - code: astro dev
    - text: starts in the foreground process and logs to the terminal.
