Health endpoint Section titled “Health endpoint” The dev server exposes a /_astro/status endpoint that returns {"ok": true} as JSON. This allows agents and other tools to check programmatically whether the dev server is ready to accept requests. This endpoint is only available in the dev server and does not exist in production builds. Tips for AI-Powered Astro Development Section titled “Tips for AI-Powered Astro Development” Start with templates : Rather than building from scratch, ask AI tools to start with an existing Astro template or use npm create astro@latest with a template option. Use astro add for integrations : Ask AI tools to use astro add for official integrations (e.g. astro add tailwind , astro add react ). For other packages, install using the command for your preferred package manager rather than editing package.json directly. Verify current APIs : AI tools may use outdated patterns. Ask them to check the latest documentation, especially for newer features like sessions and actions. This is also important for features that have seen significant changes since their initial launch, such as content collections, or previously experimental features that may no longer be experimental.
