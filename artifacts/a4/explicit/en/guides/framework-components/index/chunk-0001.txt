Hydrating interactive components Section titled “Hydrating interactive components” A framework component can be made interactive (hydrated) using a client:* directive . These are component attributes that determine when your component’s JavaScript should be sent to the browser. With all client directives except client:only , your component will first render on the server to generate static HTML. Component JavaScript will be sent to the browser according to the directive you chose.
