Building your own integration Section titled “Building your own integration” Astro’s Integration API is inspired by Rollup and Vite, and designed to feel familiar to anyone who has ever written a Rollup or Vite plugin before. Check out the Integration API reference to learn what integrations can do and how to write one yourself.
