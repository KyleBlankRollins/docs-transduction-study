Any file type that Astro supports natively, such as .astro , .ts , .jsx , and .css , can be published directly without a build step. If you need another file type that isn’t natively supported by Astro, add a build step to your package. This advanced exercise is left up to you. Come say hi! package.json data Section titled “package.json data” The library is automatically updated weekly, pulling in every package published to npm with the astro-component , astro-integration , or withastro keyword. The integrations library reads the name , description , repository , and homepage data from your package.json . Avatars are a great way to highlight your brand in the library! Once your package is published you can file a GitHub issue with your avatar attached and we will add it to your listing. Tip Need to override the information our library reads from npm? No problem!
