Testing helps you write and maintain working Astro code. Astro supports many popular tools for unit tests, component tests, and end-to-end tests including Jest, Mocha, Jasmine, Cypress and Playwright . You can even install framework-specific testing libraries such as React Testing Library to test your UI framework components. Testing frameworks allow you to state assertions or expectations about how your code should behave in specific situations, then compare these to the actual behavior of your current code. Unit and integration tests Section titled “Unit and integration tests” Vitest Section titled “Vitest” A Vite-native unit test framework with ESM, TypeScript and JSX support powered by esbuild. Use Astro’s getViteConfig() helper in your vitest.config.ts configuration file to set up Vitest with your Astro project’s settings: vitest.config.ts /// < reference types = " vitest/config " /> import { getViteConfig } from ' astro/config ' ; export default getViteConfig ({ test: { // Vitest configuration options }, }); By default, getViteConfig() will try to load an Astro config file in your project and apply it to the test environment. As of Astro 4.8, if you need to customize the Astro configuration applied in your tests, pass a second argument to getViteConfig() : export default getViteConfig ( { test: { /* Vitest configuration options */ } }, { site: ' https://example.com/ ' , trailingSlash: ' always ' , }, ); See the Astro + Vitest starter template on GitHub.
