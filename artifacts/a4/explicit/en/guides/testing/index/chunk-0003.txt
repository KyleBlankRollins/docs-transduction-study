Advanced: Launching a development web server during the tests Section titled “Advanced: Launching a development web server during the tests” You can also have Playwright start your server when you run your testing script by using the webServer option in the Playwright configuration file. Here is an example of the configuration and commands required when using npm: Add a test script to your package.json file in the project root, such as "test:e2e": "playwright test" .
