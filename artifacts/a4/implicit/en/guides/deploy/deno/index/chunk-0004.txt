You can track the progress using the “Actions” tab on your GitHub repository page, or on Deno Deploy . CLI Deployment Section titled “CLI Deployment” Complete the following steps in order. First, Install the Deno Deploy CLI . Terminal window deno install -gArf jsr:@deno/deployctl Second, Build your Astro site with your preferred package manager: Choose one of the following options. These are alternatives — use exactly one, not all of them. If you are using npm: Terminal window npm run build If you are using pnpm: Terminal window pnpm run build If you are using yarn: Terminal window yarn run build Third, Run deployctl to deploy! Choose one of the following options. These are alternatives — use exactly one, not all of them. If you are using static: Terminal window cd dist && deployctl deploy jsr:@std/http/file-server If you are using ssr: Terminal window deployctl deploy ./dist/server/entry.mjs You can track all your deploys on Deno Deploy .
