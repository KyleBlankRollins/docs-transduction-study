If two or more components on a page use the same framework, the framework will only be sent once. Accessibility: Most framework-specific accessibility patterns should work the same when these components are used in Astro. Be sure to choose a client directive that will ensure any accessibility-related JavaScript is properly loaded and executed at the appropriate time! Available hydration directives Section titled “Available hydration directives” There are several hydration directives available for UI framework components: client:load , client:idle , client:visible , client:media={QUERY} and client:only={FRAMEWORK} . See our directives reference page for a full description of these hydration directives, and their usage.
