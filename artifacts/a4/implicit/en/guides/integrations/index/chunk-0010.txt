Instead, you should use a demo project to develop and test your package inside of your project. This can be a private website only used for development, or a public demo/documentation website for your package. If you are extracting components from an existing project, you can even continue to use that project to develop your now-extracted components. Testing your component Section titled “Testing your component” Astro does not currently ship a test runner. (If you are interested in helping out with this, join us on Discord! ) In the meantime, our current recommendation for testing is: Complete the following steps in order. First, Add a test fixtures directory to your demo/src/pages directory. Second, Add a new page for every test that you’d like to run. Third, Each page should include some different component usage that you’d like to test. Finally, Run astro build to build your fixtures, then compare the output of the dist/__fixtures__/ directory to what you expected.
