Convert your Next.js Project Section titled “Convert your Next.js Project” Each project migration will look different, but there are some common actions you will perform when converting from Next.js to Astro. Create a new Astro project Section titled “Create a new Astro project” Use the create astro command for your package manager to launch Astro’s CLI wizard or choose a community theme from the Astro Theme Showcase . You can pass a --template argument to the create astro command to start a new Astro project with one of our official starters (e.g. docs , blog , portfolio ). Or, you can start a new project from any existing Astro repository on GitHub . Choose one of the following options. These are alternatives — use exactly one, not all of them.
