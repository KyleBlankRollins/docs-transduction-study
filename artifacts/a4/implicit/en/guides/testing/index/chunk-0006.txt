Installation Section titled “Installation” You can install NightwatchJS within your Astro project using the package manager of your choice. Follow the CLI steps to choose JavaScript/TypeScript, name your test folder, and select whether or not to include component testing and testing on mobile browsers. Choose one of the following options. These are alternatives — use exactly one, not all of them.
